## 🚀 Featured Project

### 🏆 Moklet Society Agency — Next-Gen Athlete Recruitment Platform
A modern web-based scouting hub designed to bridge professional sports clubs and esports franchises with elite athletic talent in Indonesia. Built with strict **Separation of Concerns (SoC)** and Clean Code architecture.

* **6 Supported Disciplines:**
  * ⚽ **Football:** Dynamic stat tracking (Goals, Assists, Ratings).
  * 🏀 **Basketball:** Performance metrics (PPG, Rebounds, Steals).
  * 🏸 **Badminton:** Career match statistics and titles.
  * 🎮 **Esports:** Live KDA ratios, win rates, and tactical roles.
  * 🏃 **Running:** Sprint timings (100m/200m) and pace endurance.
  * 🏊 **Swimming:** Dynamic lap timing and stroke style logs.
* **Core Integration:** Integrated directly with a **Google Sheets Backend Database** using asynchronous communication (`Fetch API` & Google Apps Script) to log recruitments and new athlete profiles in real-time.
* **Tech Stack:** Semantic HTML5, Advanced CSS Custom Properties (Glassmorphism UI), and Vanilla JavaScript (JSDoc Documented).
